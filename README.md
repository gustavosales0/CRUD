 ## 🚀 Funcionalidades

- Criar ou inserir novos registros ou dados ao banco de dados como cadastrar um novo usuário ou criar uma postagem. Na web, costuma ser associado ao método HTTP POST.
- Ler ou consultar algo, serve também para buscar e recuperar dados armazenados, como visualizar uma lista de produtos ou um perfil de usuário. Na web corresponde ao método HTTP GET.
- Atualizar ou modificar algo, altera informações de registros que já existem no sistema como editar dados de cadastro ou mudar uma senha. Na web utiliza os métodos HTTP PUT ou PATCH.
- Excluir ou remover, apaga dados que não são mais necessários como remover uma conta ou deletar um arquivo. Na web é associado ao método HTTP DELETE.
